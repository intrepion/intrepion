## Overview

Composer is the dependency manager for PHP. It allows you to declare the libraries your project depends on and it manages them for you.

## Getting Started

To get started with Composer, you'll need to install it. The most common way is to use the Composer installer.

### Installation

Refer to the [install](../../tools/composer/install/tools-composer-install.md) tutorial for instructions on installing Composer on your system.
