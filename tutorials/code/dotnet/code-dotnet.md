## Overview

.NET is a cross-platform development platform for building applications and services. It supports multiple languages including C#, F#, and VB.NET.

## Getting Started

To get started with .NET, you'll need to install the .NET SDK. The SDK includes the .NET runtime, compilers, and tools needed for development.

### Installation

Refer to the [install](../../tools/dotnet/install/tools-dotnet-install.md) tutorial for instructions on installing .NET on your system.
