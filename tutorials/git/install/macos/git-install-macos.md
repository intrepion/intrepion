# git Install macOS

## Requirements

- [Homebrew](./../../../homebrew/install/macos/homebrew-install-macos.md)

## Install

```bash
brew install git
```

## Check Location

```bash
which git
```

should be something like

```text
/opt/homebrew/bin/git
```
