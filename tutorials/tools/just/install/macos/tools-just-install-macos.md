# Tools just Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install just
```

## Update

```bash
brew upgrade just
```

## Check Location

```bash
which just
```

should be something like

```text
$ which just
/opt/homebrew/bin/just
```
