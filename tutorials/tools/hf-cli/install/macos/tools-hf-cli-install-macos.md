# Tools HF CLI Install macOS

## Requirements

- [Git Xet](../../../git-xet/install/macos/tools-git-xet-install-macos.md)

## Install

```bash
curl -LsSf https://hf.co/cli/install.sh | bash
```

## Update

```bash
hf update
```

## Check Location

```bash
which hf
```

should be something like

```text
$ which hf
/Users/oliverforral/.local/bin/hf
```
