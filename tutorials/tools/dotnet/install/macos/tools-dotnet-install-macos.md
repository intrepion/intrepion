# Tools .NET Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install --cask dotnet-sdk
```

## Check Location

```bash
which dotnet
```

should be something like

```text
$ which dotnet
/opt/homebrew/bin/dotnet
```
