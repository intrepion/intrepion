# Tools Visual Studio Code Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install --cask visual-studio-code
```

## Install Shell Command

Open Visual Studio Code and run `Shell Command: Install 'code' command in PATH` from the Command Palette.

## Check Location

```bash
which code
```

should be something like

```text
$ which code
/opt/homebrew/bin/code
```
