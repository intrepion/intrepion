# Tools CocoaPods Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install cocoapods
```

## Update

```bash
brew upgrade cocoapods
```

## Check Location

```bash
which pod
```

should be something like

```text
$ which pod
/opt/homebrew/bin/pod
```
