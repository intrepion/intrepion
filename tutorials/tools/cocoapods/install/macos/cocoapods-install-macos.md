# CocoaPods Install macOS

## Requirements

- [Homebrew](./../../../homebrew/install/macos/homebrew-install-macos.md)

## Install

```bash
brew install cocoapods
```

## Check Location

```bash
which pod
```

should be something like

```text
/opt/homebrew/bin/pod
```
