# Tools Git LFS Install macOS

## Requirements

- [git](../../../git/install/macos/tools-git-install-macos.md)

## Install

```bash
brew install git-lfs
git lfs install
```

## Update

```bash
brew upgrade git-lfs
git lfs install
```

## Check Location

```bash
which git-lfs
```

should be something like

```text
$ which git-lfs
/opt/homebrew/bin/git-lfs
```
