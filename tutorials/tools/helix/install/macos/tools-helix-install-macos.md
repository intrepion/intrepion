# Helix Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/homebrew-install-macos.md)

## Install

```bash
brew install helix
```

## Check Location

```bash
which hx
```

should be something like

```text
/opt/homebrew/bin/hx
```
