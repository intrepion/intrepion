# Tools llama.cpp Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install llama.cpp
```

## Update

```bash
brew upgrade llama.cpp
```

## Check Location

```bash
which llama-cli
```

should be something like

```text
$ which llama-cli
/opt/homebrew/bin/llama-cli
```
