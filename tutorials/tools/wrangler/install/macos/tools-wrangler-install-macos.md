# Tools wrangler Install macOS

## Requirements

- [nvm](../../../nvm/install/macos/tools-nvm-install-macos.md)

## Install

```bash
npm install -g wrangler
```

## Update

```bash
npm update -g wrangler
```

## Check Location

```bash
which wrangler
```

should be something like

```text
$ which wrangler
/Users/oliverforral/.nvm/versions/node/v22.17.0/bin/wrangler
```
