# Xcode Command Line Tools Install macOS

## Install

```bash
xcode-select --install
```

## Check Location

```bash
xcode-select --print-path
```

should be something like

```text
$ xcode-select --print-path
/Applications/Xcode.app/Contents/Developer
```
