# Rust Install macOS

## Install

```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
```

## Check Location

```bash
which cargo
which rustc
which rustfmt
which 
```

should be something like

```text
/Users/oliverforral/.cargo/bin/cargo
/Users/oliverforral/.cargo/bin/rustc
/Users/oliverforral/.cargo/bin/rustfmt
```
