# Tools git Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install git
```

## Update

```bash
brew upgrade git
```

## Check Location

```bash
which git
```

should be something like

```text
$ which git
/opt/homebrew/bin/git
```
