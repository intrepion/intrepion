# Tools git Uninstall macOS

## Uninstall

```bash
brew uninstall git
```

## Check Location

```bash
which -a git
git --version
```

should be something like

```text
$ which -a git
/usr/bin/git
$ git --version
git version 2.39.5 (Apple Git-154)
```
