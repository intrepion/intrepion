# Tools WezTerm Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install --cask wezterm
```

## Update

```bash
brew upgrade --cask wezterm
```

## Check Location

```bash
which wezterm
```

should be something like

```text
$ which wezterm
/usr/local/bin/wezterm
```
