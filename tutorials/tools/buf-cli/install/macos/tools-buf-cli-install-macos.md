# Tools Buf CLI Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install bufbuild/buf/buf
```

## Update

```bash
brew upgrade bufbuild/buf/buf
```

## Check Location

```bash
which buf
```

should be something like

```text
$ which buf
/opt/homebrew/bin/buf
```
