# Tools Pi Install macOS

## Install

```bash
curl -fsSL https://pi.dev/install.sh | sh
```

## Update

```bash
pi update
```

## Check Location

```bash
which pi
```

should be something like

```text
$ which pi
/Users/oliverforral/.local/bin/pi
```
