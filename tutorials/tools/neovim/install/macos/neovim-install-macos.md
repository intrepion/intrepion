# Neovim Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/homebrew-install-macos.md)

## Install

```bash
brew install neovim
```

## Check Location

```bash
which nvim
```

should be something like

```text
/opt/homebrew/bin/nvim
```
