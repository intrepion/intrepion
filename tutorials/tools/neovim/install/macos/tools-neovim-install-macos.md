# Tools Neovim Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install neovim
```

## Check Location

```bash
which nvim
```

should be something like

```text
$ which nvim
/opt/homebrew/bin/nvim
```
