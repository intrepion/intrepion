# Tools Python Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install python
```

## Update

```bash
brew upgrade python
```

## Check Location

```bash
which python3
```

should be something like

```text
$ which python3
/opt/homebrew/bin/python3
```
