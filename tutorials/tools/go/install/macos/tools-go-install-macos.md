# Go Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install go
```

## Check Location

```bash
which go
```

should be something like

```text
$ which go
/opt/homebrew/bin/go
```
