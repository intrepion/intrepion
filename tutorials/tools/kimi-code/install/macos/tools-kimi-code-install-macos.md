# Tools Kimi Code Install macOS

## Install

```bash
curl -LsSf https://code.kimi.com/install.sh | bash
```

## Update

```bash
kimi upgrade
```

## Check Location

```bash
which kimi
```

should be something like

```text
$ which kimi
/Users/intrepion/.kimi-code/bin/kimi
```
