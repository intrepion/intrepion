# SpacetimeDB Install macOS

## Install

```bash
curl -sSf https://install.spacetimedb.com | sh
```

## Update

```bash
spacetime version upgrade
```

## Check Location

```bash
which spacetime
```

should be something like

```text
$ which spacetime
/Users/oliverforral/.local/bin/spacetime
```
