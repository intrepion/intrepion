# Tools firebase Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)
- [nvm](../../../nvm/install/macos/tools-nvm-install-macos.md)

## Install

```bash
npm install -g firebase-tools
```

## Update

```bash
npm update -g firebase-tools
```

## Check Location

```bash
which firebase
```

should be something like

```text
$ which firebase
/Users/intrepion/.nvm/versions/node/v22.0.0/bin/firebase
```
