# Tools Unity Hub Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install --cask unity-hub
```

## Update

```bash
brew upgrade --cask unity-hub
```

## Setup

Open Unity Hub, sign in with a Unity ID, and install a Unity Editor from `Installs > Install Editor`.

## Check Location

```bash
ls /Applications/Unity\ Hub.app
```
