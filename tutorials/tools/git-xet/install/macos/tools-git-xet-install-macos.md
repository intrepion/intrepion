# Tools Git Xet Install macOS

## Requirements

- [Git LFS](../../../git-lfs/install/macos/tools-git-lfs-install-macos.md)

## Install

```bash
brew install git-xet
git xet install
```

## Update

```bash
brew upgrade git-xet
git xet install
```

## Check Location

```bash
which git-xet
```

should be something like

```text
$ which git-xet
/opt/homebrew/bin/git-xet
```
