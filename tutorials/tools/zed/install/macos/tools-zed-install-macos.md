# Tools Zed Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install --cask zed
```

## Update

```bash
brew upgrade --cask zed
```

## Check Location

```bash
which zed
```

should be something like

```text
$ which zed
/opt/homebrew/bin/zed
```
