# Tools Protocol Buffer Compiler Install macOS

## Requirements

- [Homebrew](../../../homebrew/install/macos/tools-homebrew-install-macos.md)

## Install

```bash
brew install protobuf
```

## Update

```bash
brew upgrade protobuf
```

## Check Location

```bash
which protoc
```

should be something like

```text
$ which protoc
/opt/homebrew/bin/protoc
```
